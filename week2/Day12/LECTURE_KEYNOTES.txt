
### There's one behavior to point out during the class.

Early in the log, before tool calling, the assistant says things like:

"We already discussed the weather in Kanpur..."

and

"We've already done this calculation..."

*** This is a useful teaching moment. ***

The assistant is relying only on memory, not on fresh data. For weather, that's actually undesirable because weather changes. After tool calling is enabled, it instead says:

"I've checked the current weather..." which is the correct behavior because it fetches live information.

*** This leads nicely to an important design principle. ***

Memory is not a cache
-----------------------
To tell the students:

Some things should be remembered.

Some things should always be refreshed.

**** Good candidates for memory
User name
Preferences
Favorite language
Favorite city
Previous requests
Conversation context

**** Bad candidates for memory
Weather
Stock prices
Currency rates
Current time
Breaking news

These should always invoke a tool.

That distinction is exactly why agents have both memory and tools.
