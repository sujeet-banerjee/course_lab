| Capability                        | Native Langfuse Evaluator                             | Offline RAGAS |
| --------------------------------- | ----------------------------------------------------- | ------------- |
| Answer relevance                  | ✅                                                     | ✅             |
| Faithfulness / Groundedness       | ⚠️ Only if retrieved context is explicitly available  | ✅             |

| Custom metrics / batch automation | Limited                                               | ✅             |
